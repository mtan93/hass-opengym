# Changelog

## 1.2.4

Initial release: openGym 1.2.4 packaged as a Home Assistant add-on.

- Ingress panel in the Home Assistant sidebar, plus an optional direct port.
- Passkey origin derived from the address in use, so there's nothing to configure
  in a normal setup.
- Profiles, passkeys and workout history stored in `/data`, so Home Assistant
  backups cover them.
- Exercise image and GIF library baked into the add-on image.
